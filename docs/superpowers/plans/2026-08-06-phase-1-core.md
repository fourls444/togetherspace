# TogetherSpace Phase 1 Core Plan

## เป้าหมาย

สร้างระบบพื้นฐานที่ผู้ใช้สามารถสมัครสมาชิก เข้าสู่ระบบ มี Profile อัตโนมัติ สร้างห้อง เข้าร่วมห้องด้วยรหัสหรือคำเชิญ และจัดการสมาชิกขั้นพื้นฐานได้ โดยใช้ Supabase เป็นผู้ดูแล Auth และสิทธิ์ข้อมูล

## ข้อกำหนดหลัก

- ใช้ Next.js App Router, TypeScript, Supabase SSR, PostgreSQL, Drizzle ORM และ Zod
- ปิด Confirm Email ใน Supabase เพื่อให้สมัครแล้วได้รับ session ทันที
- ผู้ใช้กรอก username, email และ password ตอน Signup
- `display_name` ยังไม่ต้องกรอกตอน Signup และแก้ไขได้ในหน้า Profile
- Database trigger สร้าง Profile จาก Auth user และใช้ username จาก metadata เมื่อมีค่า
- Database ใช้ RLS และ RPC เพื่อป้องกันการเข้าถึงหรือสร้างข้อมูลข้ามผู้ใช้
- ยังไม่เพิ่มระบบทดสอบอัตโนมัติหรือ dependency ที่ไม่จำเป็น

## สิ่งที่ต้องตั้งค่าเอง

1. ใส่ค่าทั้ง 3 รายการใน `.env.local` ตาม `.env.example`
2. รัน migration กับ Supabase project
3. ตรวจที่ Supabase Authentication > Providers > Email ว่า Confirm Email ปิดอยู่ หากต้องการให้สมัครแล้วเข้า Dashboard ทันที
4. หากเคยสมัครก่อนปิด Confirm Email ให้ลบผู้ใช้เดิมหรือยืนยันบัญชีนั้นก่อนทดสอบใหม่

## ยังไม่รวมใน Phase 1

- Display name ตอน Signup
- การตรวจ username ซ้ำแบบทันทีระหว่างพิมพ์
- Forgot/reset password, OAuth และ CAPTCHA เพิ่มเติม
- Calendar, Album, Board, Map, Finance, Chat, Notification และ Realtime
