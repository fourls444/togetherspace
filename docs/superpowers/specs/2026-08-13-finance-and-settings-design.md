# Finance และ Settings — แบบที่ยืนยันแล้ว

## เป้าหมาย

เพิ่มระบบค่าใช้จ่ายร่วมที่ใช้งานได้จริงในทุกประเภทห้อง และปรับหน้าตั้งค่าห้องให้อ่านง่าย กระชับ และรองรับมือถือ โดยไม่เปลี่ยน flow การยืนยันตัวตนหรือโมดูลเดิม

## Settings

- โปรไฟล์ประจำห้องมีในห้องเพื่อน คู่รัก และครอบครัวเหมือนกัน
- เดสก์ท็อปแบ่งส่วนบนเป็นสองคอลัมน์: โปรไฟล์ของฉัน และข้อมูลห้อง
- มือถือเรียงเป็นคอลัมน์เดียว
- จำกัดความกว้างช่องชื่อ ไม่ให้ยาวเต็มพื้นที่โดยไม่จำเป็น
- ปุ่มหลักใช้สี amber เฉพาะ action สำคัญ ปุ่มรองใช้สีพื้นปกติ
- ธีมห้องเป็นส่วนสั้นแยกต่างหาก
- คำเชิญอยู่ในข้อมูลห้อง โดยแยกสร้างคำเชิญและประวัติคำเชิญ
- รายชื่อสมาชิกแสดงครั้งละ 20 คนและโหลดเพิ่มได้
- การออกจากห้องอยู่ท้ายหน้าใน danger zone

## Finance

- สมาชิกทุกคนเพิ่มค่าใช้จ่ายได้
- ระบุชื่อรายการ จำนวนเงิน วันที่ ผู้จ่าย รายละเอียด และผู้ร่วมจ่าย
- แบ่งยอดได้สองแบบ: เท่ากัน หรือกำหนดยอดต่อคนเอง
- แก้ไข/ลบได้โดยผู้สร้างรายการหรือเจ้าของห้อง
- แสดงยอดใช้จ่ายรวม ยอดที่ผู้ใช้จ่าย และยอดสุทธิ
- สรุปว่าใครต้องจ่ายคืนใครเท่าไร
- กรองตามเดือนและค้นหาชื่อรายการได้
- กลไกเหมือนกันทุกประเภทห้อง แต่ข้อความแนะนำปรับตาม เพื่อน/คู่รัก/ครอบครัว
- เก็บเงินเป็นหน่วยสตางค์เพื่อลดปัญหาทศนิยม

## สิทธิ์และความถูกต้อง

- อ่านและสร้างข้อมูลได้เฉพาะสมาชิกในห้อง
- ผู้จ่ายและผู้ร่วมจ่ายต้องเป็นสมาชิกห้อง
- ผลรวมยอดแบ่งต้องเท่ากับยอดค่าใช้จ่าย
- ตรวจสิทธิ์ซ้ำทั้ง Server Action และ RLS

## งานอนาคตที่ยังไม่ทำ

- Family: หน้าผังครอบครัวแยก โดยเริ่มจากข้อมูลสมาชิกในห้อง
- Friend: หน้าโปรไฟล์แนะนำตัวแบบละเอียด ฟิลด์จะกำหนดภายหลัง
- Couple: ไม่มีโมดูลโปรไฟล์เพิ่ม แต่ยังมีโปรไฟล์ประจำห้องใน Settings
