# Crop and Settings Polish Design

## ขอบเขต

- หน้าครอปรูปใช้การลากภาพด้วยเมาส์หรือนิ้ว และใช้ล้อเมาส์หรือแถบเลื่อนสำหรับซูม
- ตัวควบคุมเหลือเฉพาะซูมและรีเซ็ต เพื่อลดความซ้ำซ้อนจากแถบเลื่อนแกน X/Y
- หน้าต่างแก้ไขรูปจัดวันที่ คำบรรยาย และปุ่มคำสั่งบนแนวเดียวกันในจอใหญ่
- ปุ่มปิดหน้าต่างแก้ไขรูปเหลือไอคอน X พร้อม aria-label
- ข้อความยืนยันลบรูปใช้ข้อความที่ผู้ใช้กำหนด
- ธีมห้องทั้ง 4 แบบอยู่แถวเดียว จอเล็กเลื่อนแนวนอนแทนการบีบการ์ด
- หน้าตั้งค่าลดพื้นที่ว่างของส่วนออกจากห้อง เอาข้อความช่วยใต้ชื่อในห้องออก และจัดปุ่มบันทึก/สร้างคำเชิญชิดขวา

## Responsive

- ครอปเป็นสองคอลัมน์บนจอใหญ่ และหนึ่งคอลัมน์บนมือถือ
- แถวแก้ไขรูปเปลี่ยนเป็นหนึ่งคอลัมน์บนมือถือ
- แถวธีมไม่ตัดเป็นหลายบรรทัด แต่เลื่อนแนวนอนได้เมื่อพื้นที่ไม่พอ

## ข้อจำกัด

- ไม่เพิ่ม dependency และไม่เปลี่ยน schema, Server Action หรือ RLS
- ใช้ Modal, Button, tokens และ CSS Modules ที่มีอยู่
