# Room Type Finance และ Global Themes

## ขอบเขตที่ยืนยัน

- สีเลือกประเภทห้อง: เพื่อนฟ้า คู่รักชมพูกุหลาบ ครอบครัวเขียวสบายตา ใช้เฉพาะสถานะเลือก/ไอคอน
- การ์ดโมดูลหน้าแรกแสดง 3 ใบต่อแถวบนเดสก์ท็อป
- ตัดพื้นหลังซ้อนของ theme scope ที่ทำให้เกิดแถบดำรอบส่วนห้อง
- โปรไฟล์ประจำห้องสูงตามเนื้อหา ไม่ยืดตามคอลัมน์ข้อมูลห้อง
- ธีมแต่ละประเภทมี 3 แบบเท่านั้น: TogetherSpace, Warm Light และธีมเฉพาะประเภท
- ธีมเปลี่ยน semantic tokens ทั้ง app shell ขณะเปิดห้อง และจำแยกตามห้องบนเครื่องนั้น

## Finance ที่ต่างกันจริง

### Friend

- Expense split เดิม
- Trip context สำหรับรวมรายการในทริป
- Shared fund สำหรับเงินกองกลาง
- Settlement status เพื่อบันทึกว่าใครคืนเงินแล้ว

### Couple

- Expense split เดิม
- Shared date fund
- หมวดค่าใช้จ่าย เช่น อาหาร เดินทาง กิจกรรม ของขวัญ และอื่น ๆ

### Family

- Expense split เดิม
- หมวดค่าใช้จ่ายบ้านแบบละเอียด
- รายรับรายเดือนของสมาชิก
- งบประมาณรายเดือนแยกหมวด

## ข้อจำกัด

- ประเภทห้องเปลี่ยนไม่ได้ จึงไม่ต้องรองรับการย้ายข้อมูล Finance ข้ามชนิด
- Board แบบแยกประเภทเก็บไว้รอบถัดไป
- ใช้ migration ใหม่ `0014` เพื่อไม่แก้ migration ที่อาจถูกรันแล้ว
