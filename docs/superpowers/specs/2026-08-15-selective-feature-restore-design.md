# Selective Feature Restore Design

วันที่: 2026-08-15

## เป้าหมาย

นำฟีเจอร์ที่ถูกย้อนออกโดย commit `ce63ef2` กลับมาจาก commit `e3961c4` โดยรักษา UI และฟีเจอร์ล่าสุดบน `origin/master` ไว้ ไม่ย้อนทั้ง commit และไม่ทับไฟล์หน้าหลักที่เพื่อนปรับใหม่โดยตรง

## ฟีเจอร์ที่จะนำกลับ

1. Family Tree สำหรับห้องประเภท `family`
   - หน้าแผนผังครอบครัว
   - เพิ่ม แก้ไข ลบ เชื่อมความสัมพันธ์ และขยับตำแหน่งสมาชิก
   - schema, migration, actions, validation และ types ที่จำเป็น
   - แสดงเมนูเฉพาะห้องครอบครัวและวางไว้ล่างสุดของ Sidebar

2. สมาชิกและโปรไฟล์
   - การเรียงรายชื่อสมาชิกแบบเดิม
   - พฤติกรรม Member Management ที่หายไป
   - `username` ยาวไม่เกิน 30 ตัวอักษร
   - `display name` ยาวไม่เกิน 40 ตัวอักษร

3. ข้อความและเส้นทางโมดูล
   - ใช้คำกลาง เช่น หน้าแรก บอร์ด ปฏิทิน อัลบั้ม แผนที่ บันทึกการเงิน และสมาชิก
   - หัวข้อบอร์ดใช้ โน้ต โหวต และเช็กลิสต์
   - คืน route fallback/alias ที่จำเป็น โดยไม่เปลี่ยน URL หลักของ UI ล่าสุด

4. การเงิน
   - คืน logic สรุปยอดและรูปแบบข้อความจำนวนเงินเดิม
   - ไม่สร้าง FinanceV2 และไม่เพิ่ม schema การเงินใหม่

5. สถานะหน้าจอ
   - คืน empty state, responsive และ loading skeleton เฉพาะส่วนที่ยังขาด
   - ปรับให้เข้ากับ CSS และ layout ล่าสุด แทนการนำ CSS เก่ากลับมาทั้งไฟล์

## ส่วนที่จะรักษาจากโค้ดล่าสุด

- แผนที่ลูกโลก หมุด และ cluster
- Album print toss และระบบลากวางรูป
- Theme ห้องและ visual effects ล่าสุด
- Room home, Photo Wall, Chat, Modal และ Settings รุ่นล่าสุด
- โครงสร้าง CSS และ typography ล่าสุด

## วิธีเชื่อมโค้ด

- คืนไฟล์ที่เป็นฟีเจอร์อิสระจาก `e3961c4` เช่น Family Tree, validation และ member sort
- สำหรับไฟล์ที่ UI ล่าสุดแก้ไปแล้ว จะเปรียบเทียบ diff และนำกลับเฉพาะ logic, props, labels หรือ event handler ที่จำเป็น
- ไม่ใช้ `git revert ce63ef2` เพราะจะนำ UI เก่าทั้งหมดกลับมา
- ไม่แก้ RLS, RPC หรือนโยบาย Supabase นอกเหนือจาก migration Family Tree ที่เคยอยู่ใน commit เดิม

## การตรวจสอบ

- ตรวจ tests ของ validation, board copy, finance summary และ Family Tree
- ตรวจ typecheck และ lint
- ตรวจ build หาก environment พร้อม
- ตรวจด้วยตาว่าเมนู Family Tree แสดงเฉพาะห้อง Family และ UI ใหม่ของแผนที่/อัลบั้มยังอยู่
