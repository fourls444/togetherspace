# Room And Board Interaction Polish Design

## เป้าหมาย

ปรับหน้าแรกห้องและหน้าตั้งค่าให้ใช้พื้นที่สมดุล พร้อมแก้ checklist และ poll ให้ตอบสนองเฉพาะจุดโดยไม่ refresh ข้อมูลทั้งหน้า

## รูปแบบหน้าจอ

- หน้าแรกห้องตัดระยะบนซ้ำในกรอบสมาชิก รายชื่อแรกชิดกับ padding ของกรอบอย่างสม่ำเสมอ
- การ์ดจำนวนสมาชิกและรหัสห้องคงรูปแบบเดิม รหัสห้องกดได้ทั้งกรอบ พร้อมสัญลักษณ์คัดลอกและข้อความยืนยันชั่วคราว
- หน้าตั้งค่าบนจอกว้างวางโปรไฟล์ของฉันกับข้อมูลห้องเป็นสองคอลัมน์ครึ่งต่อครึ่ง
- ส่วนดูแลสมาชิกและออกจากห้องใช้เต็มความกว้าง ส่วนมือถือกลับเป็นคอลัมน์เดียว

## พฤติกรรมบอร์ด

- แก้ parser ค่า checklist ให้ `"false"` เป็น `false` จริง
- checklist และ poll เก็บ state ฝั่ง client และเปลี่ยนหน้าจอทันทีแบบ optimistic
- Server Action สองรายการนี้ไม่ revalidate route หลังสำเร็จ จึงไม่ดึงหน้าใหม่ทั้งก้อน
- ถ้าบันทึกล้มเหลว ให้ย้อน state เฉพาะรายการและแสดง toast
- Poll แบบโหวตข้อเดียวจะย้ายคะแนนจากตัวเลือกเดิมไปตัวเลือกใหม่ใน state เดียว

## ขอบเขต

ไม่เพิ่ม dependency ไม่เปลี่ยน schema, migration, RLS หรือ RPC แก้เฉพาะ validation, Server Action ที่เกี่ยวข้อง และ frontend state
