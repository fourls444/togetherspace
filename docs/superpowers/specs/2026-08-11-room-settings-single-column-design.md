# Room Settings Single Column Design

## เป้าหมาย

ทำหน้าตั้งค่าห้องให้อ่านตามลำดับเดียว ลดพื้นที่ว่าง และรองรับสมาชิกจำนวนมากโดยไม่เปลี่ยน schema หรือ Server Action

## โครงหน้า

1. โปรไฟล์ของฉันในห้องนี้
2. ข้อมูลห้องสำหรับเจ้าของ พร้อมส่วนสร้างคำเชิญแบบย่อ
3. ปุ่มเปิดประวัติคำเชิญ พร้อมชื่อผู้สร้างแต่ละรายการ
4. ดูแลสมาชิกในห้องแบบกริดกะทัดรัด แสดง 20 คนแรกและเพิ่มครั้งละ 20
5. ออกจากห้อง

ผู้ใช้ทั่วไปจะเห็นเฉพาะโปรไฟล์ ข้อความสิทธิ์การจัดการ และปุ่มออกจากห้อง ส่วนรหัสห้องย้ายไปอยู่ส่วนหัวหน้าห้องพร้อมปุ่มคัดลอก

## พฤติกรรมและ responsive

- หน้าตั้งค่าเป็นคอลัมน์เดียวทุกขนาดจอ
- รายชื่อสมาชิกเป็น 2 คอลัมน์เมื่อพื้นที่พอ และ 1 คอลัมน์บนมือถือ
- ประวัติคำเชิญปิดไว้เริ่มต้น เปิดผ่านปุ่มที่มีจำนวนรายการ
- จุดกิจกรรมปฏิทินเป็นสี่เหลี่ยมมนเล็ก เรียงลงด้านล่างจากตำแหน่งเดียวกัน
- ช่องชื่อโปรไฟล์จำกัดความกว้าง ไม่ยืดตามพาเนล

## ขอบเขตข้อมูล

ใช้ข้อมูล `created_by` ที่มีอยู่ใน `room_invites` แล้วจับคู่กับรายชื่อสมาชิกปัจจุบัน ไม่มี migration, RLS, RPC หรือ dependency ใหม่
