# TogetherSpace Roadmap

## พร้อมใช้งานในปัจจุบัน

- Core room, member, invite และ room profile
- Board, Calendar, Album, Map/Places
- Finance แยกตามประเภท: ทริป/คืนเงินของเพื่อน กองเดตของคู่รัก และรายรับ/งบประมาณของครอบครัว
- ธีม 4 แบบต่อประเภทที่เปลี่ยนทั้งหน้าเว็บและจำค่าไว้เฉพาะเครื่อง
- Chat แบบ Realtime ภายในห้อง
- ผังครอบครัวสำหรับห้อง Family
- โปรไฟล์เพื่อนแบบละเอียดสำหรับห้อง Friend
- Board drag-and-drop พร้อมจัดเก็บและกู้คืนรายการ

## ลำดับถัดไป: UX/UI Quality Pass

- ตรวจ responsive ที่ 360, 768, 1024 และ 1440px
- ตรวจ keyboard navigation, focus, modal, tooltip และ aria-label
- ตรวจ empty/loading/error/success state ของทุกโมดูล
- ตรวจ typography, spacing, icon, hover และ active state ให้เป็นระบบเดียวกัน
- ทดสอบ flow จริงด้วย Owner และ Member อย่างน้อย 2 บัญชี

### หลัง Quality Pass

- Notification ภายในห้อง
- เชื่อมรูปอัลบั้มกับวันที่ในปฏิทิน
