# TogetherSpace Roadmap

## พร้อมใช้งานในปัจจุบัน

- Core room, member, invite และ room profile
- Board, Calendar, Album, Map/Places
- Finance แยกตามประเภท: ทริป/คืนเงินของเพื่อน กองเดตของคู่รัก และรายรับ/งบประมาณของครอบครัว
- ธีม 3 แบบต่อประเภทที่เปลี่ยนทั้งหน้าเว็บและจำค่าไว้เฉพาะเครื่อง

## ลำดับถัดไป

### 1. Finance Flow Verification

- รัน migration `0014` บน Supabase
- ทดสอบด้วยสมาชิกอย่างน้อย 2 คน: แบ่งยอด คืนเงิน สมทบกองกลาง และสิทธิ์ RLS
- เพิ่มแก้ไข/ลบให้ข้อมูลทริป กองกลาง รายรับ งบ และการคืนเงิน หลังยืนยัน flow สร้างแล้ว

### 2. Board Variants

- คง note, checklist และ poll เป็นแกนกลาง
- ออกแบบโจทย์เฉพาะกลุ่มเพื่อน คู่รัก และครอบครัวร่วมกับผู้ใช้ก่อนเพิ่ม schema
- หลีกเลี่ยงการแยกตารางจนกว่าจะรู้พฤติกรรมที่ต่างกันจริง

### 3. Family Tree

- ใช้สมาชิกในห้องเป็นจุดเริ่มต้น
- เพิ่มความสัมพันธ์ เช่น พ่อ แม่ ลูก คู่สมรส และพี่น้อง
- แยกหน้าออกจากสมาชิกและ Settings
- วางข้อกำหนดความเป็นส่วนตัวและสิทธิ์แก้ไขก่อนเพิ่ม schema

### 4. Friend Detail Profiles

- แยกจาก room profile ที่ใช้เพียงชื่อและรูป
- ออกแบบฟิลด์แนะนำตัวร่วมกับผู้ใช้ก่อน เช่น ชื่อเล่น ความสนใจ วันเกิด หรือช่องทางติดต่อ
- กำหนดว่าข้อมูลใดบังคับ ข้อมูลใดเลือกซ่อน และใครแก้ไขได้

### 5. Quality Pass

- ทดสอบ flow จริงทุกโมดูลด้วยผู้ใช้หลายบทบาท
- ตรวจมือถือ แท็บเล็ต keyboard navigation และ screen reader
- ลด query ซ้ำและเตรียมแนวทาง Realtime/Notification
